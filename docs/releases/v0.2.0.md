# Akalabeth MSX2 v0.2.0

Segunda versão do porte do Akalabeth para MSX2 / MSX-DOS 2.

## Novidades
- 💾 **Salvar e carregar** o jogo (`W` / `L`; `L` no título). Requer MSX-DOS 2.
- 🗺️ **Minimapa da masmorra** com neblina de exploração.
- 🎵 **Música** (4 temas originais, 3 vozes no PSG) e 14 efeitos; `M` liga/desliga.
- ⚡ **Bem mais rápido:** passo no mundo ~1,3 s → ~0,4 s; passo na masmorra ~1,3 s → ~0,6 s.
- 📖 Manual do jogador e outline técnico com status e roadmap.

## Arquivos
- `akalabeth.dsk` — disco de 720 KB com MSX-DOS 2; inicia sozinho.
- `AKALABET.COM` — só o programa.

```
openmsx -machine Philips_NMS_8250 -ext msxdos2 -diska akalabeth.dsk
```

## Problemas conhecidos
- A música às vezes engasga (investigação pendente).
- Joystick, máquinas de 60 Hz e hardware real ainda não foram testados.
