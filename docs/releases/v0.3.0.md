# Akalabeth MSX2 v0.3.0

Versão de desempenho do porte do Akalabeth para MSX2 / MSX-DOS 2.

## Novidades
- ⚡ **Mais rápido:** passo no mundo ~0,3 s (era ~0,4 s) e na masmorra ~0,55 s (era ~0,65 s); na v0.1 eram ~1,3 s.
  - Troca de páginas do vídeo na masmorra (sem cópia de 256×160).
  - Texto escrito direto na VRAM por uma rotina em assembly (antes ~5 ms por caractere).
  - Motor de som escreve só os registradores do PSG que mudaram.
  - Atlas de tiles do mundo na página 0; sprites desativados (o jogo não usa).
- Perfil por fase de cada turno para depuração.

## Correção
- Título: o logotipo grande "AKALABETH" voltou a aparecer (regressão da troca de páginas, achada no teste final).

## Observação
- Os tiles do mundo passaram a ter 44 linhas: a base das montanhas e das casas ficou mais curta.

## Arquivos
- `akalabeth.dsk` — disco de 720 KB com MSX-DOS 2; inicia sozinho.
- `AKALABET.COM` — só o programa.

```
openmsx -machine Philips_NMS_8250 -ext msxdos2 -diska akalabeth.dsk
```

## Problemas conhecidos
- A música às vezes engasga (investigação pendente).
- Joystick, máquinas de 60 Hz e hardware real ainda não foram testados.
